**ONE-TIME SETUP / 只做一次**

## 第一次准备

### ① 复制配置，填大模型 Key

先用安装程序装好 Docker Desktop、Python 3.10+ 和 Node.js。用 Windows 文件资源管理器打开 D:\graduation_design，复制 .env.example，把副本重命名为 .env。如果看不到副本，先在资源管理器的“查看”里打开文件扩展名和隐藏的项目。

用 PyCharm 打开根目录的 .env，把 LLM_API_KEY= 后面填成你自己的 DeepSeek Key。不要把 Key 发给别人或写进网页。项目默认的 MySQL、Redis、Milvus 地址已经在模板里。

如果你已经有 .env，不要再次覆盖，直接检查 Key 即可。

### ② 让 PyCharm 识别 Docker Compose

先启动 Docker Desktop。在 PyCharm 的 Settings → Plugins 中确认 Docker 插件已启用；需要时安装插件并重启 PyCharm。再到 Settings → Build, Execution, Deployment → Docker 添加 Docker Desktop 连接。右键 docker-compose.yml 选 Run。首次运行会自动创建名为 career-coach 的容器组，以后可直接在 Docker Desktop 的 Containers 页面点启动。

如果你的 PyCharm 版本没有 Docker 功能，展开下方“没有 Docker 按钮怎么办”，有一条备用命令；后端和前端仍可在 PyCharm 里点运行。

### ③ 在 PyCharm 设置后端

打开 D:\graduation_design，解释器选择 D:\graduation_design\backend\.venv\Scripts\python.exe。右上角点 Add Configuration → + → Python，填写：

- Name：FastAPI 后端
- Module name：uvicorn（选择 Module name，不是 Script path）
- Parameters：app.main:app --host 127.0.0.1 --port 8081 --reload
- Working directory：D:\graduation_design\backend
- Interpreter：D:\graduation_design\backend\.venv\Scripts\python.exe

如果没有 .venv：打开 Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → Virtualenv，位置选 D:\graduation_design\backend\.venv。然后打开 backend/requirements.txt，点击顶部的 Install requirements 提示安装依赖；已经装好的无需重复安装。

### ④ 安装前端依赖

如果 frontend/node_modules 已存在，可跳过。否则在 PyCharm 右键 frontend/package.json，选择 Run 'npm install'；等安装结束，再点 dev 左侧的运行三角。

**CHECK / 看是否跑通**

## 三个检查点

- Docker：在 Docker Desktop → Containers 展开 career-coach，查看 MySQL、Redis、Milvus 是否运行并通过健康检查。
- 后端：打开 /api/v1/ready ↗，查看 database、sessionState、vectorStore。真实大模型 Key 生效时 llm 应为 ok。
- 前端：打开 localhost:5173 ↗，用学员账号登录，进入“场景”开始训练。

Attu 是查看 Milvus 的桌面工具；连接地址 http://localhost:19530，Token root:Milvus。它不用在 PyCharm 中启动。

**HELP / 常见问题**

## 如果没打开

**前端提示无法连接服务**

先看 PyCharm 后端运行窗口是否还在运行；再打开 127.0.0.1:8081/docs。如果这个地址也打不开，先解决后端启动错误。

**后端提示数据库连接失败**

打开 Docker Desktop → Containers，确认 career-coach 中 MySQL、Redis、Milvus 正在运行，并等待健康检查通过。Docker Redis 在本机使用 6380，Milvus 使用 19530。

**能对话，但一直显示本地教练模式**

检查 D:\graduation_design\.env 的 LLM_API_KEY、LLM_BASE_URL、LLM_MODEL；保存后重启 PyCharm 的后端。

**没有 Docker 按钮怎么办？**

确认 Docker Desktop 正在运行。如果 PyCharm 中仍无 Docker 插件或无法连接，可在 PyCharm 中右键项目根文件夹 D:\graduation_design，选 Open in Terminal，仅执行一次下面的备用命令。之后容器会出现在 Docker Desktop，日常可点按钮启动。

```bash
docker compose up -d
```

**看不到前端 dev 运行按钮？**

先确认 Node.js 已安装，PyCharm 已启用 JavaScript/npm 支持。仍没有按钮时，在 PyCharm 的 frontend 文件夹上右键选择 Open in Terminal，执行一次备用命令：

```bash
npm run dev
```

**怎么关闭项目？**

在 PyCharm 的 Run 窗口分别停止后端和前端；如需停止数据服务，在 Docker Desktop → Containers 找到 career-coach，点停止按钮。不要点删除，数据会留在原来的 Docker 数据卷里。
