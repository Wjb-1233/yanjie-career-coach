# 竞品功能对比与缺口清单

- 调研日期：2026-11-08
- 调研对象：北森 AI 面试官、Interviewer.AI、HireVue、牛客、面试鸭
- 用途：判断「言阶」在功能上的缺口，按求职者模拟面试场景排序

> 注：按用户后续要求，**简历诊断、编程笔试、通用练习、故事库** 已从产品中移除；下表的「本轮补齐」保留为调研与实现记录。

## 一、竞品能力摘录

| 产品 | 核心能力 | 来源 |
|---|---|---|
| 北森 AI 面试官 | 300+ 岗位模型；三层追问（基础知识 → 方案优劣对比 → 复杂/异常场景）；专业能力 + 行为能力双维度评估；评分带行为证据链；情绪识别与安抚；支持「请再解释一下问题」；一题多测 | [北森产品文章](https://www.beisen.com/res/2538.html) |
| Interviewer.AI | 异步视频面试；AI 面试官虚拟形象；基于回答的动态追问；模拟面试（mock interview）；多语言；候选人评估报告 | [Interviewer.AI](https://interviewer.ai/) |
| HireVue | AI Interviewer；测评/评估构建器；视频面试；防作弊与身份核验；自动化与排期；与 ATS 集成；AI 可解释性与公平性验证 | [HireVue](https://www.hirevue.com/) |
| 牛客 | 校园招聘题库、笔试/编程题、面经社区、企业端 AI 面试 | [牛客企业版](https://hr.nowcoder.com/) |
| 面试鸭 | 10000+ 精选题库、按方向刷题、题目解析、会员题库 | [面试鸭](https://www.mianshiya.com/vip) |

| 报告逐题回放 | Interviewer.AI | 视频按题切段 + 逐题自评 | ✅ 已有 |

| 题库刷题 | 面试鸭 10000+ 题；牛客 | 只有每场景 6 题，无独立刷题入口 | ❌ 缺口 |

| 简历诊断/ATS 评分 | 超级简历类 | **本轮补齐：JD 关键词覆盖 + 结构分 + 修改建议 + 历史** | ✅ 本轮补齐 |

| 编程笔试（代码题） | 牛客笔试 | **本轮补齐：3 道算法题、Python/JavaScript 本地判题、提交历史** | ✅ 本轮补齐 |
| 实时提词/答案提示 | 面试鸭实时提示 | **本轮补齐：文本训练「提示卡」给结构、关键词与提醒，不给整段答案** | ✅ 本轮补齐 |
| 情绪安抚/复述问题 | 北森 | **本轮补齐：文字说「再说一遍」直接复述；语音/视频有「重听问题」；紧张时先安抚** | ✅ 本轮补齐 |
| 企业端批量筛选 | 北森/HireVue | 只有管理员，无招聘方批量评估 | ❌ 缺口（非目标用户） |
| 防作弊/身份核验 | HireVue | 无 | ❌ 缺口（本机演示场景） |
| 多语言界面 | Interviewer.AI | 仅中文 | ❌ 缺口 |

## 三、本轮已补齐

**追问强度（标准 / 三层深挖 / 压力面）**

- 场景页可全局切换，选择会记住；文本、语音、视频三个入口都生效
- 文本面试：提示词按强度注入三层追问逻辑或压力面策略，并写入会话 `depth`
- 语音/视频：房间把强度带进实时会话，标准引擎走指令、本地管线走查询参数
- 报告/历史保留 `depth`，便于对比不同强度的表现
