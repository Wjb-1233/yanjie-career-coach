1. 实时视频为浏览器本地预览 + 语音对话，不是 WebRTC 多人房间。
2. 未做国际化和多租户；单部署服务一个机构。
3. 向量库（Milvus）可选，关闭时课程检索走关键词降级。
4. 备份异机存储需要运维配置，代码层只提供脚本与定时器。
5. 评分一致性实验需要人工标注样本，属于研究性工作。
