# 毕设演示运行说明

如果希望尽量不用终端，请先看[网页版启动指南](启动指南.html)，按 PyCharm 和 Docker Desktop 的界面操作。本文保留命令行步骤作为备用。

本项目按本科毕业设计演示，不搭建 Prometheus、Alertmanager、WAF 等企业运维系统，但保留开题报告
中明确使用的核心技术：

- MySQL 保存用户、会话、评分和训练计划；
- Redis 保存训练状态；
- Milvus 保存向量知识，Attu 用于查看 Milvus；
- 大模型 API 生成话术、对话回复和评分；
- Vue 开发服务器代理 FastAPI 接口。

SQLite、内存存储和本地教练模板只作为断网兜底。正常答辩演示建议使用完整技术栈。

## 一、启动数据服务

在项目根目录复制配置并启动服务：

```powershell
Set-Location D:\graduation_design
Copy-Item .env.example .env
docker compose --project-name career-coach up -d
docker compose --project-name career-coach ps
```

在 `.env` 中填写 `LLM_API_KEY`。桌面 Attu 连接 `http://localhost:19530`，Token 为
`root:Milvus`。等 MySQL、Redis 和 Milvus 显示 healthy 后，再启动后端。
Docker MySQL 使用本机 `3308`，Redis 使用本机 `6380`，避免和已安装的服务冲突。

## 二、在 PyCharm 中启动后端

1. 用 PyCharm 打开 `D:\graduation_design\backend`。
2. Python 解释器选择 `D:\graduation_design\backend\.venv\Scripts\python.exe`。
3. 新建一个 **Python** 运行配置，并把启动目标从 **Script path** 切换为 **Module name**：
   - Module name：`uvicorn`
   - Parameters：`app.main:app --host 127.0.0.1 --port 8081 --reload`
   - Working directory：`D:\graduation_design\backend`
4. 点击运行，控制台出现 `Application startup complete` 即成功。
5. 浏览器打开 `http://127.0.0.1:8081/docs`，能看到 Swagger 接口页面即可。

如果 `.venv` 尚未创建，在 PyCharm Terminal 中执行：

```powershell
Set-Location D:\graduation_design\backend
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --constraint constraints.txt --requirement requirements-dev.txt
.venv\Scripts\python.exe -m alembic upgrade head
```

## 三、启动前端

另开一个终端执行：

```powershell
Set-Location D:\graduation_design\frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。
登录后点击左侧“下载安卓 App”可取得 APK，在同一局域网内的安卓手机上安装并连接电脑服务。
若只想在电脑上查看手机布局，可在 Chrome/Edge 按 `F12`，点击手机图标进入设备模式。

可直接使用：

- 学员：`student@example.com` / `Student123!`
- 管理员：`admin@example.com` / `Admin123!`

## 四、答辩时演示的完整流程

1. 使用学员账号登录。
2. 按面试类型、行业、岗位和难度筛选一个面试场景。
3. 创建训练并至少完成 2 轮对话，生成初次评分。
4. 展示系统生成的回复建议和五维评分。
5. 打开薄弱项四步计划，完成微课步骤和表达练习。
6. 在原场景新开会话完成至少 6 轮复练，再根据原评分建议提交改写。
7. 在原场景再次新开会话完成至少 6 轮复测，回到计划页展示五维前后分数、提升判定和下一轮建议。
8. 打开成长看板展示历史综合分和五维趋势，也可进入训练记录回看对话或导出 CSV 报告。
9. 点击“下载安卓 App”，在同一局域网内的安卓手机上安装，并展示手机端访问电脑服务。

微课作答与改写必须经大模型评价通过；离线时只保存为“待评价”，不计作完成。完整演示需要可用的大模型 Key；为了节省答辩时间，可预先准备已完成复练的账号。

## 五、大模型 Key

推荐直接写入项目根目录的 `.env`：

```dotenv
LLM_API_KEY=你的Key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

不要把 Key 写入代码或截图。真实接口临时不可用时，系统会自动使用本地模板，演示不会中断。

## 六、常见问题

- 后端提示端口占用：把 `8081` 改为其他端口，同时修改 `frontend/vite.config.ts` 的代理地址。
- 前端提示 `npm` 不存在：重新安装 Node.js，并勾选加入 PATH。
- 后端提示缺少模块：确认 PyCharm 使用的是项目 `.venv`，然后重新安装依赖。
- 页面能打开但请求失败：先确认后端控制台仍在运行，并访问 `http://127.0.0.1:8081/docs`。
- MySQL、Redis 或 Milvus 连接失败：先在项目根目录运行 `docker compose --project-name career-coach ps`，确认对应服务为 healthy。
- Attu 连不上：确认 Milvus healthy，并检查地址是 `http://localhost:19530`、Token 是 `root:Milvus`。
- 大模型一直使用本地模板：检查 `.env` 中的 Key、接口地址和模型名，修改后重启后端。训练页与报告页会明确标出是否降级。

## 七、答辩前最低检查

答辩前一天和答辩当天各检查一次：

- 后端能够启动，Swagger 能打开；
- MySQL、Redis、Milvus 状态正常，Attu 能查看 Milvus；
- 前端能够启动并登录；
- 至少四个内置面试场景都能创建训练；
- 对话能够返回内容并生成五维评分；
- 演示报告中显示使用真实大模型而不是本地兜底；
- 训练计划和成长看板能够显示；
- 准备一段录屏，以防现场网络或电脑出现意外。
