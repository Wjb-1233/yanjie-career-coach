## 关键边界

- 本次核对以用户提供的最新版 Excel 原表为准：题目为“面试情景模拟训练与话术优化系统”，场景范围是按岗位、行业、难度区分的面试场景。原表未列语音识别、语音通话、汇报、谈判或会议场景。
- 第 15 项当前是可解释的规则词组检测：输入时即时预览，提交后由后端再次检测；它不是语音情感识别，也不是独立的大模型分类器。
- 第 13 项的本地兜底用于保持训练可继续，但兜底评分不等价于大模型语义评分，界面会标明降级状态。
- “单轮响应小于 3 秒”受本地网络和所配置模型服务影响，代码提供 SSE、首 token 超时和负载测试门槛，但不能脱离真实 API 环境承诺固定耗时。
- 数据库已增加迁移版本 `20261018_0004`–`20261018_0006`。已有数据库启动新代码前须在 `backend` 目录执行 `python -m alembic upgrade head`。
