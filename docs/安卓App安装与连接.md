# 言阶 Android 测试版

这个 APK 是电脑项目的手机客户端，不包含 MySQL、Python 后端或大模型 Key。电脑服务运行时，电脑浏览器和手机 App 使用同一账号及数据；电脑关闭或服务停止后，App 无法继续联网训练。

## 在手机上安装

1. 下载 [`言阶-安卓测试版.apk`](../android-app/言阶-安卓测试版.apk)，通过 USB 或文件传输发送到安卓手机。
2. 在手机的“文件”中打开 APK，按系统提示允许这一次的“安装未知应用”，安装“言阶”。不需要给存储、通讯录或定位权限。
3. 打开 App。首页若出现“连接不到电脑服务器”，点顶部“服务器设置”，填入可访问电脑项目的地址。
4. 登录、进入场景训练；语音模式第一次点击麦克风时，允许录音权限。文字训练不需要录音权限。

当前测试版默认连接 `http://10.219.167.242:4173`，这是制作 APK 时电脑 WLAN 的局域网地址。手机和电脑必须在同一可互访的网络；若电脑后来获得新的 IP，点 App 顶部的“服务器设置”填写新地址即可，无需重装 APK。

## 电脑需要运行什么

- MySQL、Redis、Milvus 和大模型配置按现有项目要求运行。
- FastAPI 后端运行在电脑的 `127.0.0.1:8081`。
- 前端先构建，再以预览模式运行在 `0.0.0.0:4173`。电脑浏览器可打开 `http://localhost:4173`。
- 手机使用局域网地址 `http://电脑WLAN的IPv4地址:4173`，不需要临时公网通道。Windows 防火墙、校园网隔离或不同子网可能阻断连接。当前 APK 的局域网 HTTP 能力只用于调试，不应用于公网。

语音由 Android 系统识别服务处理，平台只保存识别后的文字和训练结果，不保存录音。不同手机的系统语音服务可能不同；如识别不可用，可继续使用文字模式。

简历定制面试需要安装 1.1.0 或更新版本的 APK：点击场景的文字或语音对练后，选择 `.docx` 简历，系统文件管理器会打开。提取的文字会发送给电脑后端和已配置的大模型；原始文件不保存在服务器。之前已安装旧版 App 的手机请重新下载并覆盖安装新版。

## 后续重新打包

Android 工程位于 [`android-app`](../android-app)。Windows 首次构建需要 Android SDK Platform 36、Build Tools 36.0.0、JDK 17+、Gradle 9.3.1。项目已有 Gradle Wrapper。更新前端页面不需要重新打包，因为 APK 访问电脑提供的页面；修改 Android 原生代码或默认服务器地址才需要重新生成 APK。

这是 Android 调试版 APK，未进行应用商店发布签名，也未在真实手机上完成硬件语音验收。
