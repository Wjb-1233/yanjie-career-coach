## 说明

- 文字指标：从提交回答到 SSE 首个 token / 整轮结束，含模型排队与网络往返。
- 语音指标：本地管线（Silero VAD → faster-whisper → DeepSeek → TTS），从最后一个音频包到面试官首个字幕片段。
- 首轮包含模型预热，已单独标记为 `warmup`，不计入上表。
- 这些是**本次实测量**，不是产品承诺；换机器、换网络、换模型都会变。
